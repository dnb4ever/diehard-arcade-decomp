#   3-state SM. state0: build display shadow (==scene81_game_sm state0), force g_06098668=2 -> state1.
#   state1: ATTRACT/SCENE-SELECT loop - panel UP(0x80)/DOWN(0x40) scroll g_06098668 over [0..81]

#   NOTE: with no input it parks on index 2; the director's own scene-0 selector (cur[43]=-1) also
#   picks idx 2. So 81 -> (next44=0) -> scene 0 -> scene 2 (first gameplay stage).

# ---- scene table (cart 0x26E660 / hwram 0x06072660, stride 0x50, 90 entries) ----
# Descriptor fields used by the scene system:
#   +0x00/04/08  draw/update obj handler ptrs (hwram)
#   +0x10        off16 handler (hwram)   -- scene 81: func_02206c88 (camera intro, NOT a round loop)
#   +0x14        off14 handler (hwram)   -- the scene's per-frame "content/game SM" task
#   +0x1C        SPAWN-LIST SUB-RECORD ptr (hwram): 3 spawn-list ptrs {unk0=1P-even, unk4=1P-odd,
#                                          unk8=2P/default}. 0 on scenes 79,80,81 (no player spawn).
#   +0x20/+0x24  tile/texture group args (passed to func_02216c38)
#   +0x29        scene-variant index (into per-handler record tables, e.g. 0x06074550)
#   +0x2A (42)   g_0609868e seed
#   +0x2B (43)   signed director selector  -> picks next index from +0x2C/+0x2D
#   +0x2C (44)   next-index "A"   +0x2D (45) next-index "B"
# Scene 0  sel=-1 (->2), next44=0 ; Scene 1 sel=4 (g_06098670?45:44 = 2 or loop 1), credit-wait.
# Scene 73 sel=3 (credit both==2 ? 45=74 : 44=79) ; Scene 80 next44=81 ; Scene 81 sel=0 next44=0.
